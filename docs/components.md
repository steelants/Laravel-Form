# Components

SteelAnts Laravel-Form provides the following Blade components under the `form::` namespace.

| Component | Tag | Description |
|---|---|---|
| [Form](components/form.md) | `<x-form::form>` | Form wrapper with CSRF and method spoofing |
| [Input](components/input.md) | `<x-form::input>` | Text input with datalist support |
| [Select](components/select.md) | `<x-form::select>` | Select with options array and placeholder |
| [Textarea](components/textarea.md) | `<x-form::textarea>` | Textarea |
| [Checkbox](components/checkbox.md) | `<x-form::checkbox>` | Checkbox |
| [Quill](components/quill.md) | `<x-form::quill>` | Quill rich text editor with mentions and tags |
| [Ace](components/ace.md) | `<x-form::ace>` | Ace code editor |
| [Phone](components/phone.md) | `<x-form::phone>` | Phone input with country code preselections |
| [Input Price](components/input-price.md) | `<x-form::input-price>` | Price input with VAT and currency |
| [Button](components/button.md) | `<x-form::button>` | Button with optional confirmation |

Each component has its own detailed documentation page.
